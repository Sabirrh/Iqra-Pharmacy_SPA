**Tailwind CSS**, and **Framer Motion**. The project focuses on modern
healthcare branding, smooth user experience, and elegant animations.

## 📖 Overview

IQRA Pharmacy is a modern pharmacy website designed to provide a premium
online presence with a clean healthcare-focused interface. It includes
responsive navigation, engaging animations, informative sections, and a
professional layout suitable for real-world pharmacy businesses.

``` bash

cd IQRA-Pharmacy
npm install
npm run dev
```
